Pure-Shell

A private, open-source SSH client for Android.

It connects to your servers and gets out of the way. No accounts, no analytics, no ads.

Google Play: coming soon Source on GitHub

Built for people who care where their keys live

Hardware-backed keys

Keys are made inside your phone's secure hardware (StrongBox or TEE) where it exists. They can't be exported, and every use asks for your fingerprint or screen lock. A phone without secure hardware gets a clearly labelled software key.

Strict host keys

Trust on first use, with SHA-256 fingerprints and the exact command to check them on your server. A changed server key is a hard block: nothing is sent, and there is no "connect anyway" button.

No tracking

The app itself contains no analytics, ads or crash reporting. It talks to the servers you add and to nothing else.

Open source

Licensed under the GNU GPL, version 3 or later. Read the code, build it yourself, change it.

Stays connected

Sessions survive leaving the app. A notification shows only how many are active: never hostnames, usernames or terminal text.

A keyboard that behaves

A command box with swipe typing and suggestions, bracketed paste so pasted text is never run line by line, and an app lock that covers everything the moment you leave.

Private by design

  • Hosts are stored only on your phone. Passwords are asked every time and never stored.
  • Keys live in the Android Keystore. They are not backed up and never leave the device.
  • Screenshots and the recent-apps preview are blocked unless you allow them.
  • Nothing you type or see in a session is logged.
