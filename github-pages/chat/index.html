Chat

Last updated: November 21, 2026

A public text chat room over SSH, for Pure-Shell users and testers. It runs ssh-chat (MIT license). 18 and over only.

How to connect

Use Pure-Shell or any SSH client. Connect to chat.pure-shell.eu, port 2022 (IPv4 only):

ssh -p 2022 chat.pure-shell.eu

An SSH key is required. Logins without a key and password logins are refused.

Check the host key

The fingerprint your client shows on first connect should match this one (ED25519):

SHA256:7jrCL3tt5fVK+mEOdsgFgzxxuAluADa1cI1S88Wpahk

If it does not, do not continue.

Commands

  • /help: list all commands
  • /nick name: change your nickname
  • /msg name text: send a private message
  • /quit: leave

Who is who

Your key's fingerprint is your identity. Anyone can pick any nickname, so never trust a name alone.

Rules

  • Be respectful. No spam, no illegal content, no sharing of personal data.
  • The room is moderated. Bans are at the admin's discretion.
  • Chat is public: anyone in the room sees what you write.
